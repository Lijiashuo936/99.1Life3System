## 二、技术路线：为什么选 Ventoy

### 2.1 Ventoy 是什么

Ventoy 是一个开源的**可启动 U 盘制作工具**。它的核心特点是：

> **安装一次，之后只需把 ISO 文件拷贝进 U 盘即可启动，不需要反复格式化刻盘。**

### 2.2 与传统做法的对比

| 方案 | 一个 U 盘装几个系统 | 换系统镜像的成本 |
|------|--------------------|-----------------|
| UltraISO / 软碟通 写入 | 1 个 | 每次都要重新格式化＋写入，原数据全丢 |
| Rufus / Win32DiskImager | 1 个 | 同上 |
| **Ventoy** | **可放多个 ISO，启动时任选** | **直接拷文件进去，即拷即用** |

这正是本项目选择 Ventoy 的原因：**三个系统共存于一个 U 盘**，启动时在菜单里选择，互不干扰。

### 2.3 启动原理

Ventoy 安装后会把 U 盘划分为两个分区：

```
┌─────────────────────────────────────────────┐
│  part1  数据区（exFAT，可见，盘符 E:）        │
│         ← ISO 镜像直接放这里，像普通文件一样   │
├─────────────────────────────────────────────┤
│  part2  引导区（EFI，约 32 MB，隐藏，盘符 F:） │
│         ← 存放 GRUB 引导程序                 │
└─────────────────────────────────────────────┘
```

开机时：

1. BIOS/UEFI 从 U 盘的 **part2** 引导；
2. GRUB 读取 **part1** 数据区中的 ISO 列表并生成菜单；
3. 选中某个 ISO 后，Ventoy 把它**虚拟成一块光驱**交给系统安装程序；
4. 安装程序以为自己面对的是真实光盘，正常安装。

因此系统镜像始终是"原封不动"的 ISO 文件，可随时增删，不会损坏数据区其他文件。

- 在 **Linux 系统**下制作 Ventoy 启动盘（Linux 下无法运行 `Ventoy2Disk.exe`）；

> 本项目的启动盘已在 Windows 下用 `Ventoy2Disk.exe` 制作完成，此 ISO 目前作为**备用工具**保留。

## 五、实操步骤

### 步骤 1：制作启动盘（已完成）

```
1. 管理员身份运行 ventoy-1.1.17\Ventoy2Disk.exe
2. 「设备」下拉框选中目标 U 盘（注意：会清空该 U 盘全部数据！）
3. 选项 → 分区类型选 MBR、分区格式选 exFAT、勾选「支持 Secure Boot」
4. 点击「安装」→ 等待完成
```

### 步骤 2：放入系统镜像

把下载好的 ISO 文件**直接复制**到 U 盘数据区（盘符 `E:`）即可，可建子目录分类：

```
E:\
├── ISO\
│   ├── windows11.iso
│   ├── ubuntu-24.04.iso
│   └── 其它系统.iso
└── ventoy\          ← 插件配置目录（可选）
```

> 无需任何"写入"操作，拷完就能用，即拷即用。

### 步骤 3：从 U 盘启动

```
1. 笔记本插上 U 盘，开机
2. 按启动热键：联想 F12 / 戴尔 F12 / 惠普 F9 / 华硕 Esc / 宏碁 F12
   （Windows 内也可：「设置 → 系统 → 恢复 → 高级启动 → 使用设备」）
3. 在设备列表中选择 U 盘（显示为 UEFI: 你的U盘名）
4. 进入 Ventoy 菜单 → 方向键选 ISO → 回车启动
```

### 步骤 4：进阶玩法（Ventoy 插件）

项目内的 `plugin\ventoy\ventoy.json` 展示了 Ventoy 支持的增强能力，可按需启用：

| 配置项 | 作用 | 适用场景 |
|--------|------|---------|
| `menu_alias` | 给 ISO 起中文别名 | 把 `cn_windows_10_...iso` 显示成"我的 Windows 10 系统" |
| `theme` | 自定义启动菜单主题、配色、背景图 | 制作带有本校/项目标识的菜单 |
| `menu_class` | 按系统类型自动配图标（Ubuntu / Deepin / RedHat） | 菜单更直观 |
| `auto_install` | 加载应答文件实现**无人值守自动安装** | 批量装机、实验环境快速部署 |
| `control` | 控制菜单模式、文件过滤等行为 | 细节调优 |

> 该文件内容为 Ventoy 官方**示例配置**（引用了 MX-19.1、Windows 10 LTS 2019 等官方文档样例），实际使用时替换为自己镜像的路径即可。

## 八、备注

1. **命名待统一**：`REDMIN.MD` 的标题写作"一生**一**系统"，而项目目录名为 `99.1Life3System`（Life **3** System）、正文亦为"一台笔记本运行**三个**系统"。推测标题存在笔误，建议统一为「一生三系统」。
2. **数据安全提醒**：用 Ventoy 安装系统时，选择的是**笔记本内置硬盘**作为安装目标，操作前务必确认已备份重要数据。
3. **安全启动**：启动盘已开启 Secure Boot 支持，但部分 Linux 发行版仍需在 BIOS 中临时关闭 Secure Boot 才能引导。
